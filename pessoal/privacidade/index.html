Política de Privacidade — Assistente Pessoal

Última atualização: 24 de novembro de 2026.

Esta política se aplica ao Assistente Pessoal, ferramenta de uso individual hospedada sob o domínio sevenetals.com. Ela só é usada pela própria pessoa que a autoriza, na própria conta Google.

Quais dados são acessados

  • Gmail — ler, buscar, organizar (marcadores, arquivar, marcar como lido), redigir rascunhos e enviar e-mails na caixa de quem autoriza. Não inclui exclusão permanente de mensagens.
  • Outros serviços Google (Drive, Planilhas, Agenda, Documentos) — somente se a pessoa autorizar, para organizar os próprios arquivos e compromissos.

Como os dados são usados

Os dados são usados exclusivamente para automatizar a organização pessoal de quem autoriza. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. Os dados permanecem na própria conta Google; nenhuma cópia é mantida em servidor externo além do necessário para executar cada tarefa.

Retenção e revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Revogar interrompe imediatamente qualquer automação que dependa dele.

Contato

Dúvidas sobre esta política: contato@sevenetals.com.
